# Habit Tracking Web App

A minimal modern habit tracker you can run locally in the browser.

## Features

- Add daily habits
- Track completion for any day
- Automatic streak count per habit
- Monthly calendar view with completion progress
- Local storage persistence (no backend required)

## Run locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
